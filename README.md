# Todo API

A small HTTP API built with Node.js, Express, and TypeScript.

Currently exposes `GET /health`. Todo endpoints and persistence are planned.

## Commands

- `npm install`
- `npm run dev` - dev server on http://localhost:3000
- `npm run typecheck` - type check without emitting
- `npm run build` - compile to `dist/`
- `npm start` - run the built server
